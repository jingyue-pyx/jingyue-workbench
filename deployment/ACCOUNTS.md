# 轻量内测账号：已发布，新账号登录与云对话恢复通过

## 用户体验与边界

- 注册：显示名、登录账号、密码。显示名为 1–40 位，可在账号页修改；账号 3–32 位，按 NFKC 规范化并忽略大小写，注册后固定；后台 UUID 才是项目归属依据。
- 密码 15–128 位，支持密码短语；不收集手机号、邮箱，不做短信/邮箱验证，暂不提供自助找回、改密或管理员界面。
- 注册、登录、账号设置页面为自包含响应式页面；未认证时不加载项目缓存和沙箱。
- 日常登录使用账号和密码，旧共享账号仅能凭原密码认领原有工作区。首个注册用户不会成为管理员或获得旧项目。
- 同一个数据库，多账号共用项目表；每次查询、写入、删除、恢复均由已验证会话绑定 `owner_id`，不接受前端指定所有者。

## 开源复用与自有部分

已安装并使用 **Passport 0.7.0 + passport-local 1.0.0（MIT）** 的用户名密码认证策略。不是复制另一套完整 SaaS。项目自己的注册、PostgreSQL 会话存储、归属检查和 UI 接口在该策略周边实现。

- https://www.passportjs.org/packages/passport-local/
- https://www.passportjs.org/concepts/authentication/sessions/

密码使用 Node 原生 scrypt（N=131072、r=8、p=1、随机盐、恒定时间比较）；不保存明文。随机会话令牌仅通过 HttpOnly Cookie 发送，库中保存令牌 SHA-256 摘要，12 小时过期，可退出撤销，最多保留 10 个有效会话。生产 Cookie 具备 Secure、SameSite=Strict、__Host 前缀。登录及写接口检查请求来源、JSON 类型和体积。

账号表只额外授权运行账号修改 `display_name` 列，不给予密码、管理员标识、禁用标识或 DDL 修改权限。初始化 SQL 仍由独立建表账号显式执行。

## 本机缓存与标签页

项目 IndexedDB、历史 IndexedDB、附加 IndexedDB、本机设置/草稿与应用 Cookie 均按用户 UUID 分隔。只有已证明的原账号可读取旧浏览器缓存。退出不会批量删除草稿，也不会自动批量上传旧项目。

标签页保留启动时的身份标识。后台以会话为准，并检查请求的“预期账号”是否匹配；切换 Cookie 后，旧页请求被拒绝，不能悄悄将旧页项目保存给新账号。前端在账号切换广播、窗口重新获得焦点和接口拒绝时锁定旧页面。

这不是对同一操作系统用户/浏览器开发者工具的加密隔离；共用电脑仍应使用各自浏览器配置文件。浏览器沙箱仍是 WebContainers，不增加云沙箱或后台任务。

## 发布前必须完成

1. 备份现有云库；以独立初始化账号执行 `sql/003-accounts.sql`，再执行 `sql/004-account-runtime-grants.sql`。现有项目及其 owner_id 不变，运行程序不自动建表。
2. 保留旧 `WORKBENCH_OWNER_ID`、共享账号与已轮换密码；旧账号不符合账号格式时设置合法且保留的 `JINGYUE_LEGACY_ACCOUNT`，由旧密码在首次登录时认领。
3. 先部署但保持默认 `JINGYUE_AUTH_MODE=basic`。完成准备后再启用 `accounts`；注册默认关闭，需显式 `JINGYUE_REGISTRATION_OPEN=1`。
4. 默认内测上限 20 人；每人每日 20 次模型请求、全站每日 100 次，均使用数据库计数。可设置 `JINGYUE_MAX_ACCOUNTS`（最大 100）、`JINGYUE_USER_DAILY_REQUESTS`（最大 100）、`JINGYUE_GLOBAL_DAILY_REQUESTS`（最大 500）。两个每日模型次数项可分别显式设为 `0` 关闭该项次数限制；账号容量不能设为 `0`。关闭次数限制不关闭身份校验、登录防刷、并发、请求超时和单任务输出/修复预算，也不改变供应商计费，费用仍按实际模型调用产生。先部署支持 `0` 的代码再改环境变量；回滚旧代码前先恢复正数限额，避免旧版本拒绝启动。计数表不删除或清零。这是次数限制，不是费用硬封顶；注册不验证手机号/邮箱，无法阻止一个人注册多个账号。
5. 本机/生产制品验收后，仍需在正式域名检查 Cookie、原账号迁移、两账号隔离、跨标签页、数据库唤醒与云保存恢复。
6. **2026-09-28 用户确认沿用现有 RDS Serverless 私网明文连接，发布非敏感数据的公网内测，并同意 20 个账号、每人每日 20 次及全站每日 100 次模型请求上限；不是费用硬封顶。** 此例外不代表敏感数据或正式生产安全达标；此类用途应改用已验证的 TLS 数据库连接。网站 HTTPS 不能替代后端到数据库的链路加密。

回退：关闭注册；保留新增表与数据；切回 basic 会恢复原共享工作区，不能将它当作多用户安全访问模式。不要删除账号表或重新分配历史 owner_id 来“恢复”。
